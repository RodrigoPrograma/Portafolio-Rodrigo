# 💼 Rodrigo Alonzo | Portfolio

Portfolio profesional desarrollado para presentar mi perfil, experiencia, proyectos y evolución como desarrollador web.

El proyecto busca combinar una interfaz moderna y responsive con una arquitectura organizada, buenas prácticas de desarrollo y una experiencia de usuario clara.

## ✨ Objetivos

* Presentar mi perfil profesional y experiencia de forma clara y moderna.
* Mostrar proyectos de desarrollo Frontend, Backend y WordPress.
* Documentar mi evolución profesional mediante un roadmap interactivo.
* Aplicar buenas prácticas de arquitectura y organización del código.
* Construir una interfaz responsive y accesible.
* Optimizar el rendimiento y el SEO del sitio.

---

## 🚀 Tecnologías

* **React** — Construcción de la interfaz.
* **TypeScript** — Tipado estático y mayor seguridad en el código.
* **Vite** — Entorno de desarrollo y build.
* **React Router** — Gestión de rutas.
* **Tailwind CSS** — Estilos y diseño responsive.
* **Motion** — Animaciones e interacciones.
* **React Icons** — Iconografía.

---

## 📁 Estructura del proyecto

```text
src/
```

## 🧩 Secciones

El portfolio incluye diferentes secciones orientadas a mostrar tanto mi perfil profesional como mi evolución técnica:

## 📱 Responsive Design

El sitio está desarrollado siguiendo un enfoque **mobile-first**, utilizando las utilidades responsive de Tailwind CSS para adaptar la interfaz a diferentes tamaños de pantalla.

Se busca mantener una experiencia consistente en:

* 📱 Mobile
* 📲 Tablet
* 💻 Desktop
* 🖥️ Pantallas de mayor resolución

## 🛠️ Instalación

Cloná el repositorio:

```bash
git clone https://github.com/RodrigoPrograma/Portafolio-Rodrigo.git
```

Ingresá al directorio del proyecto:

```bash
cd Portafolio-Rodrigo/Rodrigo-portfolio
```

Instalá las dependencias:

```bash
npm install
```

Iniciá el servidor de desarrollo:

```bash
npm run dev
```

Para generar el build de producción:

```bash
npm run build
```
